1xx

Informational

"Hold on, I'm working on it."
Rarely seen by users. The server has received the headers and is telling the client to send the body.

2xx

Success

"Here you go."
The action was successfully received, understood, and accepted.

  • 200 OK
  • 201 Created
  • 204 No Content
3xx

Redirection

"Go over there."
Further action needs to be taken to complete the request (usually jumping to a new URL).

  • 301 Moved Perm.
  • 302 Found (Temp)
  • 304 Not Modified
4xx

Client Error

"You messed up."
The request contains bad syntax or cannot be fulfilled. The client is at fault.

  • 400 Bad Request
  • 401 Unauthorized
  • 403 Forbidden
  • 404 Not Found
5xx

Server Error

"I messed up."
The server failed to fulfill an apparently valid request. The developers need to fix this.

  • 500 Internal Error
  • 502 Bad Gateway
  • 503 Unavailable
