The View (Presentation)

This is what the user sees (HTML/CSS). It is "dumb"—it doesn't know how to calculate things or save to a database. It just displays data given to it and captures user clicks.

button.onClick -> send to Controller
radio_button_unchecked

The Controller (Logic)

The middleman. It accepts input, validates it, and decides which Model to update. It keeps the View and Model separate so they don't depend on each other directly.

if (input.isValid) Model.update()
database

The Model (Data)

The single source of truth. It manages the data, logic, and rules of the application. When data changes, it notifies observers (usually the View) to update.
