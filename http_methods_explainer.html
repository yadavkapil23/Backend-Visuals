table_chart At a Glance Comparison

Method Primary Use Request Body? Safe? Idempotent?
GET Retrieve a resource No Yes Yes
POST Create a new resource Yes (Data to create) No No
PUT Update/Replace existing resource Yes (New data) No Yes
DELETE Remove a resource Usually No No Yes

* Idempotent means if you make the same request multiple times, the result on the server is the same as if you did it once. (e.g., Deleting user ID 5 twice is the same as deleting it once - they are gone either way. But POSTing a message twice creates two messages).
