# Backend Visualisation Learning Hub

An interactive learning platform with educational materials covering backend development concepts including APIs, HTTP methods, authentication, and more.

## About

This learning hub contains a collection of interactive guides, simulators, and labs for backend development concepts. Each module is self-contained and provides hands-on experience with:

- API fundamentals
- HTTP methods and status codes
- Security concepts (JWT, sessions, cookies, MFA)
- Architecture patterns (MVC)
- Frameworks (FastAPI)

## Contents

- What is an API? - Interactive Guide
- HTTP Methods Explainer
- HTTP Status Codes Guide
- HTTP vs HTTPS Simulator
- Path vs Query Parameters
- Headers & Cookies Explainer
- Cookies Deep Dive
- Sessions vs Tokens
- JWT Interactive Guide
- Multi-Factor Authentication (MFA)
- MVC Architecture Simulator
- MVC Controller Simulator
- Routing Simulator
- Middleware Simulator
- CRUD Operations Lab
- Error Handling Guide
- Input Validation Lab
- Python FastAPI Guide
- Build Custom API Guide

## How to Use

1. Open `index.html` in your web browser to access the main navigation
2. Click on any guide to begin learning
3. Each guide contains interactive elements to help you understand the concepts

## GitHub Pages Deployment

To deploy this site on GitHub Pages:

1. Create a new repository on GitHub
2. Push all these files to your repository
3. Go to your repository settings
4. Under "Pages" section, select source as "Deploy from a branch"
5. Select the main branch
6. Your site will be available at `https://<your-username>.github.io/<repository-name>`

## Local Development

If you want to run locally with a server, you can use the included server:

1. Install Node.js
2. Run `npm install` to install dependencies
3. Run `npm start` to start the server
4. Visit `http://localhost:3000` in your browser
