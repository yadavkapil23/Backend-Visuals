URLs aren't just addresses; they are data structures.
Learn to distinguish between Identity (Path) and Modification (Query).

1. Path Parameter (The "ID") help

Used to identify a specific resource. Part of the URL structure.

/products/

2. Query Parameters (The "Modifiers") help

Key-value pairs after the ?. Used to filter, sort, or paginate.

const router = express.Router(); router.get('/products/:id', (req, res) => { ... });

Path Parameters

/users/:id
  • check Essential: Required to locate the resource.
  • check Hierarchical: /country/state/city
  • check Identifying: "Which specific item?"
Also commonly referred to as "URL Parameters".
tune

Query Parameters

?sort=asc&page=2
  • check Optional: The page usually works without them.
  • check Non-Hierarchical: Order doesn't matter.
  • check Modifying: "How do you want the list?"
