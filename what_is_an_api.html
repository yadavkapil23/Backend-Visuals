What is an API?

Think of an API as a Waiter in a restaurant.
You (the app) order food (data). The waiter takes your order to the kitchen (server) and brings back your meal. You don't need to know how to cook; you just need to know how to order.

The Client

This is your mobile app, web browser, or any software that needs data. It's the Customer at the table. It doesn't know how to prepare the data, it just knows what it wants.

api
handshake

The API

The Waiter. It takes the request (Order), validates it, carries it to the server, and brings back the response (Food). It is the set of rules that lets two programs talk to each other.

dns

The Server

The Kitchen. This is where the database and logic live. It receives the order from the API, finds the raw ingredients (data), cooks them (processing), and hands the result back.
