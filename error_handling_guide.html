Error Handling

Things will go wrong. Servers crash, databases timeout, and users send bad data.
Error Handling is the art of failing gracefully instead of blowing up.

dangerous Unsafe Code

1. print("App Started")
2. data = get_user_input()
3. result = 100 / data // data is 0
4. print("Success!")

verified_user Safe Code (Try-Catch)

try:
print("App Started")
result = 100 / 0
print("Success!")
catch (Error e):
print("Caught Error!")
log_error(e)
shield

SAVED

App continues running.
