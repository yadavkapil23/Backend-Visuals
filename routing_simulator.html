Understanding Routing

Routing is the traffic cop of the web. It takes a URL (like /profile) and decides which Code to run or which Page to show.

Server / Client Code

The router checks these rules from top to bottom. The first one that matches the URL wins.

path == "/"
home Render HomeComponent
path == "/about"
info Render AboutComponent
path matches "/users/:id"
person Render ProfileComponent
Extracted Params: { id: "..." }
* (Wildcard)

route Static Routing

Directly mapping a fixed path to a page.
Example: /about always loads the "About Us" page. It's exact and simple.

alt_route Dynamic Routing

Using placeholders to handle unlimited variations.
Example: /users/:id handles /users/1, /users/bob, etc. The router "captures" the dynamic part for code to use.

search_off 404 / Fallback

The safety net. If no other rules match the URL, the "Wildcard" (*) route catches it and displays an error page, preventing the app from crashing.
